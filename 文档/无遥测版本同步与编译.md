## 2. 在 Linux 编译环境统一同步

将 `xquic-no-telemetry-sync.tar.gz` 上传到 `/data/quic/`。以下整段在 Bash 终端执行；`set -euo pipefail` 只影响子 Bash，失败不会因为这个设置直接退出 SSH 登录 shell。

```bash
bash <<'BASH'
set -euo pipefail
FILE_SRC=/data/quic/zz_xquic_3090
PACKAGE=/data/quic/xquic-no-telemetry-sync.tar.gz
test -d "$FILE_SRC/mini"
test -f "$PACKAGE"
STAGING=$(mktemp -d /data/quic/xquic-no-telemetry-sync-XXXXXX)
tar -xzf "$PACKAGE" -C "$STAGING"
(cd "$STAGING" && sha256sum -c SHA256SUMS)

BACKUP=$(mktemp --suffix=.tar.gz /data/quic/xquic-before-no-telemetry-XXXXXX)
tar -czf "$BACKUP" -C "$FILE_SRC" \
  mini demo include/xquic/netins_udp.h src/netins_udp src/transport
printf '覆盖前源码备份：%s\n' "$BACKUP"

while IFS= read -r relative_path; do
  cp -- "$STAGING/$relative_path" "$FILE_SRC/$relative_path"
done < "$STAGING/SYNC_FILES.txt"
rm -f -- "$FILE_SRC/demo/netins_udp_telemetry_json.c" \
  "$FILE_SRC/demo/netins_udp_telemetry_json.h"
(cd "$FILE_SRC" && sha256sum -c "$STAGING/SHA256SUMS")
printf '18 个文件同步并校验完成；已移除两个专用输出文件。\n'
BASH
```

备份为上面打印位置的 tar.gz 文件。该步骤只覆盖清单中的 18 个文件，删除明确列出的两个文件；本机 CMakeLists.txt、第三方库、证书、测试数据及现有构建目录不在覆盖范围内。

## 3. 重新编译 x86_64 服务端

路径沿用此前编译指南。若依赖的实际安装位置不同，只修改下面的依赖变量。重连 SSH 后可直接重新执行整段，不依赖旧会话的变量。

```bash
bash <<'BASH'
set -euo pipefail
FILE_SRC=/data/quic/zz_xquic_3090
FILE_LINUX_TLS=/data/quic/zz_xquic_3090/third_party/Tongsuo-8.3.0
FILE_LINUX_EVENT=/data/quic/libevent-2.1.12-stable
FILE_LINUX_ZLOG=/data/quic/zlog-1.2.18
FILE_SERVER_BUILD=$(mktemp -d "$FILE_SRC/build-file-server-no-telemetry-XXXXXX")
: "${FILE_SRC:?源码目录不能为空}" "${FILE_SERVER_BUILD:?构建目录不能为空}"
printf '本次新构建目录：%s\n' "$FILE_SERVER_BUILD"

cmake -S "$FILE_SRC" -B "$FILE_SERVER_BUILD" \
  -DCMAKE_C_COMPILER=/usr/bin/gcc \
  -DCMAKE_CXX_COMPILER=/usr/bin/g++ \
  -DCMAKE_BUILD_TYPE=Release \
  -DXQC_ENABLE_MINI_API=ON \
  -DXQC_ENABLE_TESTING=OFF \
  -DSSL_TYPE=babassl \
  -DSSL_INC_PATH="$FILE_LINUX_TLS/include" \
  -DSSL_LIB_PATH="$FILE_LINUX_TLS/libssl.a;$FILE_LINUX_TLS/libcrypto.a" \
  -DLIBEVENT_INCLUDE_DIR="$FILE_LINUX_EVENT/include" \
  -DLIBEVENT_LIBRARY="$FILE_LINUX_EVENT/.libs/libevent.a" \
  -DLIBEVENT_PTHREADS_LIBRARY="$FILE_LINUX_EVENT/.libs/libevent_pthreads.a" \
  -DZLOG_INCLUDE_DIR="$FILE_LINUX_ZLOG/src" \
  -DZLOG_STATIC_LIB="$FILE_LINUX_ZLOG/build_x86_64/lib/libzlog.a"
cmake --build "$FILE_SERVER_BUILD" \
  --target netins_udp_mini_api_server --parallel "$(nproc)"

EXE="$FILE_SERVER_BUILD/mini/netins_udp_mini_api_server"
file "$EXE"
readelf -h "$EXE" | grep Machine
"$EXE" --version
HELP_OUTPUT=$("$EXE" --help 2>&1 || true)
printf '%s\n' "$HELP_OUTPUT" | grep -F -- '--scheduler'
if printf '%s\n' "$HELP_OUTPUT" | grep -F -- '--telemetry-output'; then
  echo '失败：产物仍然包含遥测参数' >&2
  exit 1
fi
sha256sum "$EXE"
printf '服务端新产物：%s\n' "$EXE"
BASH
```

若 TLS 静态库实际位于 `Tongsuo-8.3.0/lib/`，将 SSL_LIB_PATH 两个路径改成该子目录。构建完成后，按原部署方法将新产物放到测试脚本配置的服务端运行目录；源码目录下编译成功并不会自动替换脚本实际调用的可执行文件。
